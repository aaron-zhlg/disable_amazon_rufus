# Disable Amazon Rufus Chrome Extension

A simple Chrome extension to hide the Amazon Rufus AI assistant panel from your shopping experience.

## Installation Guide

1. **Download the Extension**
   - Ensure you have the `disable_amzn_rufus` folder on your computer.

2. **Open Chrome Extensions Page**
   - Open Google Chrome.
   - In the address bar, type `chrome://extensions/` and press Enter.

3. **Enable Developer Mode**
   - In the top-right corner of the Extensions page, toggle the **"Developer mode"** switch to **ON**.

4. **Load the Extension**
   - Click the **"Load unpacked"** button that appears in the top-left corner.
   - Navigate to and select the `disable_amzn_rufus` folder.

5. **Done!**
   - The extension is now installed.
   - You can pin it to your browser toolbar for easy access.
   - Click the extension icon to toggle Rufus ON or OFF anytime.
